Ajouter un partage Samba

Renseigne le serveur et, si nécessaire, ses identifiants. Le mot de passe est conservé dans un fichier root en mode 0600, jamais dans le tableau.
Le 0777 évite les refus de droits côté Linux. Il ne donne aucun droit supplémentaire sur le serveur : connecté comme Yoann, les autorisations Samba de Yoann restent appliquées.
Prérempli sous /mnt/smb/, mais tu peux choisir un sous-dossier plus précis.
